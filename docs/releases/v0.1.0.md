# Robot to Codex v0.1.0

将兼容语音机器人的听写内容输入到当前 Codex 聊天。支持无线配对、口述草稿、明确发送和退出口令。

## 下载与启动

- `RobotToCodex-Setup-0.1.0.exe` 为 Windows x64 安装包，安装时可创建桌面图标。
- `RobotToCodex-win-x64-0.1.0.zip` 为便携版，完整解压后双击 `Start.cmd`。
- `SHA256SUMS.txt` 提供两个安装资产的 SHA256 校验值。

运行环境为 Windows 10 2004（19041）或更新 / Windows 11 x64。完整安装包与便携目录包含 .NET 运行环境。

## 主要功能

- 机器人与电脑在同一局域网无线配对，保存绑定后自动重连。
- 说“开启语音输入”后口述正文，文字先进入当前 Codex 输入框。
- 屏幕核对后单独说“发送”，说“退出模式”恢复机器人聊天。
- 提供识别记录、托盘和深浅色外观。
- 包含通用机器人接入指南、CVI1 协议及无键盘示例。
- 启动器经资源管理器打开应用，避免继承宿主包身份导致配对目录分叉。

## 兼容与使用条件

机器人固件需要实现本项目的 CVI1 接口与安全配对。其他机器人请先按 [接入指南](https://github.com/Carti111/robot-to-codex/blob/v0.1.0/docs/ROBOT_INTEGRATION.md) 适配，已有实机反馈来自开发用 ESP-SparkBot 改造固件。

语音识别由机器人及其 ASR 服务提供。使用时保持电脑程序运行，并在 Codex 中点击目标输入框。完整协议见 [协议文档](https://github.com/Carti111/robot-to-codex/blob/v0.1.0/docs/PROTOCOL.md)。

安装包尚未进行代码签名，Windows 可能显示发布者未知。首次安装后的局域网访问按系统防火墙提示配置，便携版也提供可手动运行的局域网规则脚本。
