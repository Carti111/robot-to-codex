# Development notes

## Current development snapshot — 0.2.1

- Robot-only Windows companion for dictating into the current Codex composer.
- LAN discovery, expiring wireless Security2 pairing and TLS transport.
- Device-local dictation mode, real STT turns, authorization before input, explicit send/exit and no automatic replay.
- Robot/history/settings navigation, visible pairing code, dark/light appearance and tray.
- Public custom-robot integration guide, wire protocol, isolated example and build/test instructions.
- Generic cvi-robot profile and robot-provided discovery name; legacy esp-sparkbot profile retained.

This is a source publication, not a newly numbered release. No new firmware image or installer release is implied. Product/assembly version remains 0.2.1.
